# Contributing to Ethical Hacking Hands-on Lab

Thank you for your interest in contributing to this educational project! We welcome contributions from security professionals, educators, and enthusiasts.

## Code of Conduct

- This project is for **educational purposes only**
- Respect all laws and regulations regarding cybersecurity
- Do not use this material for unauthorized access or testing
- Share knowledge responsibly and ethically
- Be respectful and constructive in all interactions

## How to Contribute

### 1. Fork the Repository
```bash
git clone https://github.com/pradippandey555/Ethical-Hacking-Uni-Project---Hands-on-Lab.git
cd Ethical-Hacking-Uni-Project---Hands-on-Lab
git remote add upstream https://github.com/pradippandey555/Ethical-Hacking-Uni-Project---Hands-on-Lab.git
```

### 2. Create a Feature Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Make Your Changes

#### For New Labs:
- Follow the documentation format specified in README.md
- Include clear objectives, prerequisites, and step-by-step guides
- Add configuration files where applicable
- Include troubleshooting sections
- Test all commands and instructions

#### For Configuration Files:
- Add comments explaining each configuration option
- Include safe default values
- Document any security considerations
- Add usage examples

#### For Documentation:
- Use clear, beginner-friendly language
- Include code blocks with syntax highlighting
- Add links to relevant resources
- Verify all external links are working

## Commit Message Format
```
[TYPE] Brief description

Detailed explanation of changes (if needed)

Type options:
- [ADD] - New content or feature
- [UPDATE] - Update existing content
- [FIX] - Bug fixes
- [IMPROVE] - Improvements to existing content
- [DOCS] - Documentation updates
```

## Review Process

All contributions go through review:
- Maintainers will review your PR
- We may request changes or clarifications
- Once approved, your PR will be merged
- Your contribution will be acknowledged
